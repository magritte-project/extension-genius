# extension-genius

A Magritte extension for genius.com

## Installation

### For Developers

The Magritte project uses [`asdf`](https://asdf-vm.com/) to manage tooling and [`just`](https://just.systems/) to handle tasks. Follow the Getting Started directions to install `asdf` on your machine. Once you've installed `asdf`, you can bootstrap your development environment:

```sh
$ ./bootstrap
```

Bootstrapping the development environment creates a `.env` file. Edit the entries the `.env` file to be suitable for your local working environment.
